# English Sentence Trainer MVP

영어 본문을 최대 10장까지 연속 촬영해 기기 내 OCR로 추출하고, 문장별 단어 순서 맞추기를 제공하는 Android 앱입니다. 각 장의 OCR이 끝나면 다음 부분 촬영, 촬영 완료, 마지막 사진 다시 찍기를 선택할 수 있습니다. 촬영 완료 시 결과가 촬영 순서대로 합쳐져 전체 편집 화면에 표시됩니다.

## 실행

Android Studio에서 이 폴더를 열고 Gradle Sync 후 Android 6.0(API 23) 이상의 실제 기기에서 `app`을 실행합니다. 첫 촬영 시 카메라 권한을 허용하세요. 카메라 없이 확인하려면 메인 화면의 **샘플 본문으로 테스트**를 누릅니다.

ML Kit 라틴 문자 인식 모델은 앱에 번들되며, 인식·문장 처리·퀴즈 데이터는 서버로 보내지 않습니다. Manifest에는 인터넷 권한이 없습니다.
