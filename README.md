# English & Japanese Sentence Trainer MVP

영어 본문을 최대 10장까지 연속 촬영해 기기 내 OCR로 추출하고, 한국어 자동 번역과 문장별 단어 순서 맞추기를 제공하는 Android 앱입니다. 각 사진을 촬영한 뒤 사진 위 선택 영역을 손가락으로 직접 조절하므로 옆 문제나 사진을 OCR에서 제외할 수 있습니다. 각 장의 OCR이 끝나면 다음 부분 촬영, 촬영 완료, 마지막 사진 다시 찍기를 선택할 수 있습니다. 촬영 완료 시 결과가 촬영 순서대로 합쳐져 전체 편집 화면에 표시됩니다.

`학습 시작`으로 확정한 마지막 본문은 기기 내부에 자동 저장됩니다. 다음 실행부터 메인 화면의 **저장된 본문 다시 학습**으로 사진 촬영 없이 불러올 수 있습니다.

일본어 모드에서는 교과서 단어를 카메라로 촬영해 일본어 OCR 결과를 직접 수정한 뒤, 화면에 손가락이나 펜으로 써서 정답을 확인할 수 있습니다. 기본 히라가나·가타카나 46자와 탁음·반탁음 연습 문제도 내장되어 있습니다. 손글씨 정답은 일본어 ML Kit 인식 후보와 정확히 일치할 때만 통과합니다.

손글씨 학습 화면은 가로 전투 화면으로 전환됩니다. 정답을 쓰면 학생 영웅이 단어 공격으로 책 보스의 HP를 1 줄이고, 오답이면 보스가 반격합니다. 모든 문제를 맞히면 보스를 처치하며 게임은 점수 결제나 서버 없이 완전히 로컬에서 진행됩니다.

## 실행

Android Studio에서 이 폴더를 열고 Gradle Sync 후 Android 6.0(API 23) 이상의 실제 기기에서 `app`을 실행합니다. 첫 촬영 시 카메라 권한을 허용하세요. 카메라 없이 확인하려면 메인 화면의 **샘플 본문으로 테스트**를 누릅니다.

ML Kit 한국어·일본어 문자 인식 모델은 앱에 번들됩니다. 일본어 손글씨 인식 모델과 영어→한국어 번역 모델은 최초 사용 시 한 번 내려받으며, 이후 인식과 번역은 기기에서 실행됩니다. 촬영 이미지와 본문은 서버로 전송하지 않습니다.
